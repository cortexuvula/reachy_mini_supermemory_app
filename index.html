Reachy Mini Supermemory

long-term memory supermemory.ai web search tavily time-aware voice agent privacy mode

A voice companion app for Reachy Mini that remembers across sessions, searches the live web, and knows what "tonight" means.

Two memory layers — a small always-loaded inline block of durable facts injected into every session, plus a larger searchable supermemory.ai archive for the long tail. Tavily-backed web search for anything past the model's training cutoff, with queries auto-anchored to the user's local date so sports scores and breaking news resolve correctly. Reachy curates them itself — you just talk.

What's inside

  • Inline memory — short bullet list of high-signal facts (under 3000 chars) loaded into every system prompt. Curated by the LLM via the manage_memory tool.
  • Supermemory.ai integration — semantic search across every containerTag your API key can reach, including memories from other agents on the same account.
  • Auto-discovered tag scope — recall finds your containers automatically; toggle which ones to read from in the /supermemory/ settings page.
  • Web search via Tavily — the web_search tool answers questions outside the model's training cutoff (news, sports scores, weather, prices). Every query is auto-prefixed with the user's local date / time / timezone so Tavily's answer summariser resolves "tonight" / "today" against the real calendar. Optional time_range parameter filters to day / week / month / year for recency-sensitive queries; URLs are preserved so the robot cites domains aloud.
  • Date & time awareness — every session prompt includes an ambient <<CURRENT_DATETIME>> stamp resolved at session start (timezone from SUPERMEMORY_USER_TIMEZONE, OS local, or UTC), so the model has date context without a tool round-trip. The get_current_time(timezone?) tool covers minute precision and cross-zone queries ("what time is it in Tokyo?").
  • Privacy mode (opt-in) — push either antenna to instantly mute the mic and flush the speaker. Both antennas fold down to ~86° as a clear visual indicator that Reachy isn't listening. Push again to resume; after turning privacy off it takes a few seconds before the robot will respond while the audio pipeline reinitialises. Auto-digest also skips transcripts captured during privacy so a side conversation doesn't end up in the archive.
  • Auto-digest (opt-in) — after idle, summarises the conversation and writes one entry to the archive so nuance isn't lost.
  • Robot-native — runs in console mode on the Reachy Mini itself; voice in and out flows through the robot's mic and speaker, not the browser.

How to install

  1. Make sure you already have the Reachy Mini dashboard installed.
  2. Connect to your Reachy Mini.
  3. Open the "Applications" tab in the dashboard.
  4. Find Reachy Mini Supermemory in the list of available applications.
  5. Click Install. The dashboard handles dependencies.
  6. Set SUPERMEMORY_API_KEY in .env (or visit /supermemory/ on the robot to paste it from the browser).
  7. Optionally: paste a TAVILY_API_KEY in the Web search section to enable web_search, and pick an IANA timezone in the Date & time section.
  8. Start the app and say hello.

Configuration

Every behaviour is env-var-tunable: which tags recall searches, the inline-memory char cap, the realtime VAD threshold (so the robot's mic doesn't trip on its own speaker), the user's timezone, the Tavily backend, and the optional auto-digest model. Full table in the README.

Requires a supermemory.ai account. Optional: a Tavily key (1,000 free searches/month) for web_search, and a Hugging Face token with inference-provider access for the optional digest feature.
